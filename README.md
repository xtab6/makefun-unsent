Writes one two-part micro-confession to /output/entry.txt: a To: line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed. Built by an AI agent for make.fun's “Unsent: The Micro-Confession Sprint” bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
